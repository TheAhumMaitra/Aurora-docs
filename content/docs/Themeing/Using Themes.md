> [!IMPORTANT]
> Please install external themes carefully. Make sure you trust the author. It may contain malicious scripts!

In Aurora, you can use the theme switcher to switch between themes. Aurora's theme switches many application's theme, it's so gorgeous that you might fell in love with it!


## Supported Applications
**It supports various default applications**
1. `waybar`
2. `hyprland`
3. `Visual Studio Code`
4. `btop`
5. `rofi`
6. `Neovim (With Lazyvim)`
7. `wlogout`
8. `All Aurora's GUI`
9. `GTK`
10. `Zed`
11. `Ghostty`

> [!TIP]
> To open theme switcher GUI, please press `SUPER + T`

## Install external themes
>[!IMPORTANT]
> All themes must be stored in `~/.config/themes/`

### Clone the theme
```bash
cd ~/.config/themes && git clone GIT_REPO_URL
```
**Done! Enjoy. You check for any installation script in the theme's git repo**

>[!NOTE]
> You can also set your theme using Aurora's CLI. View more at Aurora's CLI section
